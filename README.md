# ponto ❤️

Site pessoal feito para a minha namorada.

- `index.html` — o cantinho principal, sempre atualizado, com fotos, motivos
  e uma mensagem pra ela. Tema visual inspirado na Clove, do Valorant.
- `aniversario.html` — guardado como lembrança do aniversário dela.
- `style.css` — estilo compartilhado pelas duas páginas.
- `common.js` — música, fundo animado, corações, lightbox e o que é comum
  às duas páginas.
- `home.js` / `aniversario.js` — o que é específico de cada página.

Feito por Carlos Eduardo Milan Ferreira ([@dudumilan](https://github.com/dudumilan)).
