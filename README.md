# ponto ❤️

Site pessoal feito para a minha namorada.

- `index.html` — o cantinho principal, sempre atualizado, com fotos, motivos
  e uma mensagem pra ela. Tema visual inspirado na Clove, do Valorant.
- `motivos.html` — os 100 motivos completos, um por um.
- `galeria.html` — galeria completa de fotos. Pra adicionar uma foto nova:
  solte o arquivo nessa mesma pasta e acrescente o nome dele na lista
  `fotos` no topo do `galeria.js`.
- `aniversario.html` — guardado como lembrança do aniversário dela.
- `style.css` — estilo compartilhado por todas as páginas.
- `common.js` — música, fundo animado, corações, lightbox, menu de
  navegação e os 100 motivos (usados tanto no botão da home quanto na
  página `motivos.html`).
- `home.js` / `motivos.js` / `galeria.js` / `aniversario.js` — o que é
  específico de cada página.
